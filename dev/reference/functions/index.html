Other functions

The remaining supported functions, as they are documented in the source. The functions meant for everyday use are on Main functions and types. A name that is not exported is written with the module name, as in ODEParameterEstimation.merge_options.

ODEParameterEstimation.create_ordered_ode_system — Method
create_ordered_ode_system(name, states, parameters, equations, measured_quantities)

Create an OrderedODESystem with completed equations and ordered variables.

Arguments

  • name: Name for the system
  • states: State variables
  • parameters: System parameters
  • equations: System equations
  • measured_quantities: Equations for measured quantities

Returns

  • Tuple of (OrderedODESystem, measured_quantities)

ODEParameterEstimation.merge_options — Method
merge_options(base::EstimationOptions; kwargs...) -> EstimationOptions

Create a new EstimationOptions struct by merging keyword arguments with an existing options struct. This is useful for temporarily overriding specific options.

Examples

base_opts = EstimationOptions()
new_opts = merge_options(base_opts; abstol=1e-10, diagnostics=true)

ODEParameterEstimation.print_uncertainty_results — Method
print_uncertainty_results(uq::UncertaintyReport; io = stdout)

Terminal summary of the parameter uncertainty report. Public reports are in physical coordinates [parameters, initial_conditions]; local IFT coordinates are printed separately when available.

source
ODEParameterEstimation.uq_reliability — Method
uq_reliability(outcome) -> UQReliabilityAssessment

Return the independent reliability axes for a requested UQ outcome. A single run can establish availability and pass local numerical gates, but it cannot certify repeated-sampling coverage; empirical calibration therefore remains :not_assessed_by_single_run for every individual report.

source
ODEParameterEstimation.validate_options — Method
validate_options(opts::EstimationOptions) -> Bool

Validate that the options struct has sensible values. Throws warnings for potentially problematic configurations.

Returns

  • true if options are valid
  • false if there are critical issues
