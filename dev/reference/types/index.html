Other types

The option types and the types that come with a result, as they are documented in the source. The names meant for everyday use are on the previous page. A name that is not exported is written with the module name, as in ODEParameterEstimation.InterpolatorMethod.

The types to do with uncertainty, UncertaintyReport and those around it, belong to an experimental part of the package. See Uncertainty.

ODEParameterEstimation.AbstractUQOutcome — Type

Common supertype for requested uncertainty-quantification outcomes.

source
ODEParameterEstimation.EstimationFlow — Type
EstimationFlow

How the estimate is made, chosen with the flow option.

  • FlowStandard (default): the algebraic method.
  • FlowDirectOpt: local optimization alone, from a random start.
source
ODEParameterEstimation.InterpolatorMethod — Type
InterpolatorMethod

The curve fits that estimate the derivatives of the data, listed in the interpolators option.

  • InterpolatorAAA: a rational approximation. Suits exact or nearly exact data.
  • InterpolatorGP: a Gaussian process. Suits noisy data.
  • InterpolatorGPUncertainty: a Gaussian process that also estimates the noise in the data. Needed for compute_uncertainty.
  • InterpolatorCustom: a function of your own, from custom_interpolators.

The default list runs nine curve fits. The values not named here are internal and may change in any release.

source
ODEParameterEstimation.OrderedODESystem — Type
OrderedODESystem

A ModelingToolkit system together with its parameters and states in a fixed order. Results list their values in this order.

The keyword constructor of ParameterEstimationProblem builds one from a System, so you rarely need to.

Fields

  • system: the ModelingToolkit system.
  • original_parameters: the parameters, in order.
  • original_states: the states, in order.
source
ODEParameterEstimation.PolishMethod — Type
PolishMethod

The optimizer that refines each solution against the data, chosen with the polish_method option.

  • PolishLeastSquares (default): Levenberg–Marquardt on the residuals.
  • PolishBFGS, PolishLBFGS: minimize the sum of squares directly, with the Optim.jl method of that name.
source
ODEParameterEstimation.ResultProvenance — Type
ResultProvenance

Structured lineage metadata for a parameter-estimation result.

Fields

  • primary_method::Symbol: :algebraic or :direct_opt
  • interpolator_source::Union{Nothing, Symbol}: Which interpolator produced the candidate
  • rescue_path::Symbol: :none, :algebraic_resolve_t0, :algebraic_resolve_shoot, :direct_opt_fallback
  • source_shooting_index::Union{Nothing, Int}: Shooting-point index that produced the candidate
  • source_candidate_index::Union{Nothing, Int}: Stable candidate index within the producing phase
  • pre_polish_error::Union{Nothing, Float64}: Error before polishing, when applicable
  • post_polish_error::Union{Nothing, Float64}: Error after polishing, when applicable
  • polish_applied::Bool: Whether a polishing stage was applied
  • representative_assignments::OrderedDict{Num, Float64}: Values assigned only because variables were already known structurally unidentifiable
  • structural_fix_set::OrderedDict{Num, Float64}: Representative structural fix set derived from SI structural outputs
  • template_status::Union{Nothing, Symbol}: Template dimension status after structural fixing (2026-08: replaced the vestigial residualfixset + before/after status pair — no residual-repair mechanism ever existed, so the pair was identical by construction)
  • equations_dropped_by_rank_trimming::Vector{Int}: Equation indices removed by rank-based template trimming
  • practical_identifiability_status::Symbol: Practical/numerical identifiability assessment status for this flow
  • numerical_advisory::Union{Nothing, NumericalIdentifiabilityAdvisory}: Best-effort advisory numerical diagnostics and heuristic recommendations
  • notes::Vector{Symbol}: Additional lineage/debug notes
source
ODEParameterEstimation.SystemSolverMethod — Type
SystemSolverMethod

How the polynomial systems are solved, chosen with the system_solver option.

  • SolverHC (default): homotopy continuation, which finds every solution.
  • SolverTrustRegion: a trust-region method started from several points.
  • SolverLevenbergMarquardt: Levenberg–Marquardt from one point.

The last two are local solvers and can miss solutions.

source
ODEParameterEstimation.UQReliabilityAssessment — Type
UQReliabilityAssessment

Orthogonal reliability axes for a UQ outcome. These deliberately do not collapse software availability, local numerical validity, interval width, selection conditioning, and empirical calibration into a single status flag. UncertaintyReport.status remains as a backward-compatible summary.

source
ODEParameterEstimation.UncertaintyError — Type
UncertaintyError

Thrown instead of returning an UncertaintyUnavailable when the uncertainty cannot be worked out and the options say uq_failure_policy = :throw. Its outcome field is that UncertaintyUnavailable.

source
ODEParameterEstimation.UncertaintyReport — Type
UncertaintyReport

Propagated parameter uncertainty through the implicit function theorem sensitivity matrix.

Σx = S · Σd · S' where S = -(∂F/∂x)⁻¹·(∂F/∂d). For the default package UQ, Σ_d is the estimator sampling covariance of the observable jet, conditional on learned GP hyperparameters. Legacy latent GP posterior covariance is kept as a separate diagnostic concept.

source
ODEParameterEstimation.UncertaintyUnavailable — Type

Typed outcome returned when UQ was requested but cannot be computed honestly.
